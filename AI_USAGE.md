# AI Usage – FocusBoard

## AI Tools Used

- ChatGPT (OpenAI)

## How AI Was Used

ChatGPT was used as an assistance tool during development for:

- Understanding the assignment requirements and planning the project structure.
- Assistance with React component implementation.
- Debugging and resolving development issues.
- Implementing task management functionality and Local Storage persistence.
- Creating the Focus Notes carousel and responsive CSS.
- Preparing project documentation.

## Representative Prompts

1. "Help me build a responsive task management dashboard using React."
2. "Help me implement task creation, editing, deletion, search, and filters."
3. "Create a Focus Notes carousel with previous and next navigation."
4. "Help me make the dashboard responsive for mobile and desktop."

## AI-Generated Suggestions Reviewed

AI suggestions were reviewed and tested during development. One suggested placement for the Add New Task button was initially incorrect. It was corrected to align with the "Your Work in Focus" heading, based on the intended design.

The carousel layout and CSS were also adjusted after checking the rendered application.

## Testing and Verification

The developer manually tested the following functionality:

- Creating tasks
- Editing tasks
- Deleting tasks
- Searching tasks
- Filtering by status and priority
- Local Storage persistence after refreshing
- Focus Notes carousel navigation
- Responsive layouts

## Developer Responsibility

The final implementation, design decisions, code review, testing, and project submission were handled by the developer with AI assistance.
